# 원본 기획서 v0.2

이 문서는 **받은 원문을 그대로 보존한 것**이다. 고치지 않는다.

`00`~`20` 문서는 이 원문을 출발점으로 삼아 수치와 구조를 붙인 것이고,
원문과 어긋나는 결정이 생기면 그 문서 안에 어긋나는 이유를 적는다.
원문을 소급해서 고쳐 맞추지 않는다 — 무엇을 왜 바꿨는지가 남아야 한다.

작성 시점: v0.2 (2026-09-17 수령)

---

## 1. 게임 한 줄 요약

여러 도시를 오가며 교역하고, 캐러밴과 인물을 성장시키며 자신만의 상단을 만들어가는 실시간 상인 게임.
핵심은 전투 자체가 아니라 정보·교역·이동·인물 육성을 조합해 더 좋은 선택을 하는 것이다.

## 2. 핵심 게임 경험

플레이어가 반복해서 경험하는 핵심은 다음과 같다.

정보 수집 → 판단 → 교역 → 이동 → 사건 발생 → 성장 → 더 큰 교역

단순히 "싸게 사서 비싸게 판다"가 아니라,

* 어디에서 무엇을 살 것인가?
* 지금 가격이 오를 것인가 떨어질 것인가?
* 어떤 루트가 가장 효율적인가?
* 위험한 루트를 감수할 것인가?
* 어떤 인물을 데리고 갈 것인가?
* 지금 전직을 시도할 것인가?
* 원하는 전직을 위해 다른 도시까지 이동할 것인가?

같은 판단이 계속 발생하도록 한다.

## 3. 게임 세계

### 3.1 여러 도시와 마을

세계에는 많은 마을·도시가 존재한다. 각 지역은 생산물과 소비 특성이 다르다.

예시: 농업 마을 / 광산 도시 / 어촌 / 목재 마을 / 직물 도시 / 항구 / 상업 도시 / 수도 / 군사 도시

각 지역은 단순한 상점 역할이 아니라 경제적·문화적·인물 육성상의 특징을 가진다.

### 3.2 지역 특성

각 도시에는 고유한 특성이 존재할 수 있다. 예:

* 곡물 생산량이 많음
* 철 가격이 저렴함
* 해상 교역이 발달함
* 기병 관련 기술이 발달함
* 특정 직업의 전직에 유리함
* 특정 이벤트가 자주 발생함

도시의 상태는 고정되지 않고 사건이나 세계 상황에 따라 변할 수 있다.

## 4. 교역 시스템

### 4.1 기본 구조

각 도시마다 상품의 가격이 다르다. A 도시에서 밀 100G, B 도시에서 밀 160G.
플레이어는 가격 차이를 이용해 이익을 얻는다. 하지만 가격은 고정되지 않는다.

### 4.2 가격에 영향을 주는 요소

기본 생산량 / 소비량 / 재고량 / 플레이어들의 거래 / NPC 상인의 거래 / 지역 이벤트 /
계절 / 재해 / 전쟁 / 축제 / 소문 및 정보

따라서 동일한 루트가 항상 최고의 루트가 되지 않도록 한다.

## 5. 정보 시스템

이 게임에서 정보는 중요한 자원이다. 예:

* "북쪽 지방에서 곡물 생산량이 크게 줄었다."
* "이번 주에 항구에 대규모 상선이 들어온다."
* "동쪽 도시에서 철광이 발견됐다는 소문이 있다."

정보에는 정확도와 신뢰도가 존재할 수 있다. 따라서 플레이어는 단순히 정보를 받는 것이 아니라
정보를 모으고 → 신뢰도를 판단하고 → 직접 계산해서 행동해야 한다.
친구나 다른 플레이어와 정보를 교환하는 것도 가능하다.

## 6. 이동 시스템

### 6.1 직접 캐릭터 이동 X

초기 방향은 필드에서 캐릭터를 직접 움직이는 방식이 아니라, 캐러밴/상단이 도시와 도시 사이를
이동하는 방식이다. 예: 농촌 마을 → 수도 2시간, 농촌 마을 → 항구 3시간.

### 6.2 실시간 세계

게임 세계의 시간은 계속 흐른다. 플레이어가 접속하지 않아도 세계 시간이 진행될 수 있는 구조를 고려한다.
캐러밴은 출발 시간과 도착 예정 시간을 기준으로 이동한다.
따라서 "지금 출발하면 언제 도착하는가?"가 중요한 판단이 된다.

## 7. 캐러밴

플레이어는 자신의 상단/캐러밴을 운영한다. 캐러밴에는 다음 요소가 존재할 수 있다.

화물 / 운송 능력 / 이동 속도 / 호위 인원 / 인물 편성 / 위험도 / 이동 비용

많이 실으면 수익은 커지지만 느려지거나 위험해질 수 있다.

## 8. 인물 시스템

### 8.1 고유 캐릭터

캐릭터는 단순한 "전사 A", "상인 B" 같은 직업 카드가 아니다.
각각 고유한 이름과 외형을 가진 하나의 인물이다. 예: 리안, 블래스티, 기타 고유 인물들.

따라서 플레이어가 "나 리안 얻었어."라고 말할 수 있는 수준의 캐릭터 수집 욕구를 목표로 한다.
캐릭터는 능력치뿐 아니라 외형과 개성 자체가 수집 가치를 갖도록 한다.

## 9. 직업 및 전직 시스템

### 9.1 직업은 캐릭터를 만드는 성장 경로

고유 캐릭터를 처음부터 완성된 상태로 획득하는 것이 아니라, 직업 트리를 성장시켜
최종 단계에서 고유 캐릭터를 획득하는 구조를 고려한다.

```
검사 → 해적 → 해적왕 → 리안
검사 → 창잡이 → 창의신 → 블래스티
```

즉, 최종 전직 단계 자체가 고유 캐릭터가 되는 구조다.

### 9.2 최종 캐릭터의 차별화

최종 캐릭터는 단순히 상위 등급의 숫자 상승이 아니다.

해적왕 리안 — 해상 교역/전투 특화, 선박 관련 능력, 특정 상황에서 특수 능력
창의신 블래스티 — 육상 전투 특화, 전열 관련 능력, 특정 전투 상황에서 특수 능력

처럼 캐릭터마다 플레이 방식에 영향을 주는 고유 특성을 가진다.

## 10. 랜덤 전직

전직 과정에는 확률적 요소를 넣는 방향을 검토한다. 예:

```
검사 → 해적   : 60%
검사 → 창잡이 : 30%
검사 → 기타   : 10%
```

플레이어는 다양한 정보를 이용해 원하는 전직의 확률을 높일 수 있다.
핵심은 단순한 "강화 성공/실패"가 아니라 **어떤 성장 경로로 갈 것인가?** 를 랜덤성과 함께 결정하는 것이다.

## 11. 전직에 필요한 자원

전직에는 시간이 필요하다. 또한 전직과 이동은 서로 연결된 자원 구조를 가진다.

* 이동하면서 시간 경과
* 전직 준비/훈련에도 시간 소요
* 특정 도시에서 전직 가능
* 전직을 위해 해당 도시까지 이동해야 할 수 있음

따라서 "지금 바로 전직할 것인가?"와 "원하는 전직 조건이 좋은 도시까지 이동할 것인가?" 사이에서 선택하게 된다.

## 12. 전직 확률과 도시/정보

전직 확률을 단순히 고정하지 않고 세계의 조건에 따라 달라지게 하는 방향을 검토한다.

* 특정 도시가 검술로 유명함 → 검사 계열 전직에 유리
* 특정 지역에 유명한 기마 교관이 있음 → 기병 계열 전직에 유리
* 특정 이벤트 발생 → 특정 직업 계열에 보너스

플레이어는 이러한 정보를 수집하고 스스로 확률을 계산한다.
예: "내 계산으로 해적왕 루트가 약 80% 정도 되겠는데?" 그리고 실제로 20%의 다른 결과가 나올 수도 있다.
이러한 예측과 결과의 차이 자체가 게임의 긴장감이 된다.

단, 실제 확률은 공정하게 동작해야 하며 지나친 실패 스트레스를 방지할 장치를 검토한다.

## 13. 전직 결과 되돌리기

원하지 않는 전직 결과가 나왔을 경우 이전 직업으로 돌아가 다시 전직을 시도하는 시스템을 검토한다.

```
검사 → 창잡이 → 원하지 않음 → 검사로 복귀 → 다시 전직 시도
```

단, 무제한 무료 반복이 되면 확률이 사실상 의미가 없어지므로 시간 / 비용 / 재료 / 기회비용 등의
비용을 부여하는 방식을 검토한다.

## 14. 6인 캐러밴 편성

캐러밴에는 최대 6명의 인물을 배치하는 구조를 검토한다. 초기에는 직업 자체가 역할을 가진다.

전투 계열 / 상인 계열 / 운송 계열 / 정보 계열 / 생산 계열 / 특수 계열

다만 최종 캐릭터가 존재하기 때문에 단순히 "역할 하나 = 캐릭터 하나"로 고정하지 않고,
캐릭터마다 고유한 능력과 역할을 조합한다.

## 15. 전투 시스템

### 15.1 전투의 위치

전투는 메인 콘텐츠가 아니라 교역 과정에서 발생하는 위험 요소로 둔다.
예: 위험한 산길 이동 → 도적 습격 → 전투 발생.

전투의 결과는 교역에 영향을 준다: 화물 손실 / 이동시간 증가 / 캐러밴 피해 / 추가 비용 / 안전한 통과.

따라서 전투에서 패배했다고 게임 전체가 끝나는 구조는 지양한다.

## 16. 자동전투

현재 방향은 자동전투를 우선적으로 검토한다. 플레이어가 전투 중 직접 캐릭터를 조작하는 것이 아니라,
편성 → 출전 → 자동전투 → 결과 의 형태를 기본으로 한다.
이를 통해 게임의 중심을 전투가 아닌 교역과 상단 운영에 유지한다.

## 17. 캐릭터 전투 특성

자동전투지만 캐릭터의 개성이 실제 전투에서 드러나도록 한다.
각 캐릭터는 기본 능력치 / 고유 특성 / 스킬 / 직업에 따른 능력 / 최종 캐릭터 고유 효과를 가질 수 있다.

해적왕 리안 — 해상 전투 특화, 적 후방 공격, 해상 교역 관련 효과
창의신 블래스티 — 전열 전투 특화, 전방 공격, 전열 보호 효과

스킬은 전투를 완전히 결정하는 필살기보다는 캐릭터의 개성을 보여주고 상황별 차이를 만드는 요소를 우선적으로 고려한다.

## 18. 전투와 플레이어별 경쟁력

중요한 문제 중 하나는 모든 플레이어가 결국 동일한 최적 조합을 사용하는 상황이다.
따라서 "가장 강한 캐릭터 6명을 모으면 끝"이 되는 구조는 피한다. 이를 위해 다음 요소를 검토한다.

지역별 전투 환경 / 교역 루트별 위험 / 해상·육상 차이 / 전투 상황 / 캐릭터 조합 /
플레이어의 교역 전략 / 캐러밴 구성

즉, 절대적으로 가장 강한 조합보다는 **상황에 따라 가치가 달라지는 조합**을 목표로 한다.

## 19. 전투 화면의 역할

전투를 실제 화면으로 보여줄 경우에도 전투 하나하나가 게임의 핵심이 되지 않도록 한다.
전투는 "내가 얻고 성장시킨 캐릭터가 실제로 어떻게 싸우는가?"를 보여주는 시각적 보상의 역할도 가진다.
따라서 캐릭터의 외형과 스킬 연출은 중요하다.
최종 캐릭터가 등장했을 때 "와, 이 캐릭터를 얻었다."라는 느낌을 줄 수 있어야 한다.

## 20. 플레이어 간 경쟁

멀티플레이를 고려할 경우 핵심은 단순한 전투 PvP가 아니라 경제적 경쟁이다.

같은 상품을 놓고 경쟁 / 같은 교역 루트 경쟁 / 정보 교환 / 정보의 선점 /
특정 지역의 가격 변화 / 희귀 상품 확보 / 캐러밴 간 충돌 / 플레이어별 전문화

다만 멀티플레이는 초기 개발 목표라기보다 게임의 핵심 루프가 재미있다는 것이 확인된 후
확장하는 방향을 우선 고려한다.

## 21. NPC 상인

플레이어가 없는 세계에서도 경제가 움직이도록 NPC 상인을 둘 수 있다.
NPC 상인은 상품 구매 / 상품 판매 / 특정 교역 루트 이용 / 가격에 영향 / 플레이어와 경쟁 등의 행동을 한다.
이를 통해 세계가 정적인 시장이 되지 않도록 한다.

## 22. 이벤트

세계에는 주기적으로 사건이 발생한다.

흉년 / 풍년 / 광산 발견 / 전쟁 / 축제 / 항구 봉쇄 / 해적 출현 / 전염병 /
대규모 무역선 입항 / 특정 직업 관련 이벤트

이벤트는 상품 가격뿐 아니라 이동·전직·전투·정보에도 영향을 줄 수 있다.

## 23. 플레이어 성장

초기: 개인 상인 → 중기: 소규모 캐러밴 → 후기: 대형 상단 → 장기: 여러 교역 루트를 운영하는 상단

성장 요소: 자본 / 캐러밴 / 운송수단 / 인물 / 전직 / 도시 정보 / 교역망 / 시설·거점 / 희귀 캐릭터

## 24. 게임의 핵심 차별점

① **가격을 보는 게임이 아니라 가격의 이유를 보는 게임** — "왜 이 도시에서 이 상품이 싸지?"를 생각하게 한다.
② **이동 자체가 의사결정** — "조금 더 빨리 갈 것인가?" "위험하지만 수익 높은 길을 갈 것인가?"
③ **정보가 자원** — 다른 플레이어와 정보를 공유하거나 직접 확인하고 판단한다.
④ **캐릭터를 뽑는 것이 아니라 만들어가는 수집** — 직업 트리를 따라 성장하면서 최종적으로 해적왕 → 리안 같은 고유 캐릭터를 획득한다.
⑤ **랜덤성과 판단의 결합** — 확률을 높이고 결과를 예측할 수 있지만 결과가 완전히 확정되지는 않는다.
⑥ **전투는 교역의 위험을 관리하는 수단** — 전투가 주인공이 아니라 상인의 선택과 위험 관리에 영향을 주는 시스템이다.

## 25. 현재 예상 게임 루프

```text

    ↓

    ↓

    ↓
캐러밴 편성
    ↓
이동
    ↓
이벤트 / 시장 변화 / 전투
    ↓
도착
    ↓
판매
    ↓

    ↓
캐릭터 육성 / 전직
    ↓

    ↓
더 큰 교역
```

## 26. 현재 가장 중요한 미해결 문제

**세계** — 시대/문화권, 판타지 여부, 세계 크기, 도시 개수, 도시 간 거리, 도시별 특성
**교역** — 상품 종류, 가격 계산 방식, 플레이어 간 시장 영향, NPC 시장 영향, 경제 리셋 여부
**캐릭터** — 캐릭터 획득 방법, 직업 트리 규모, 최종 캐릭터 수, 캐릭터별 외형 차이, 능력치 구조
**전직** — 정확한 확률 구조, 확률을 높이는 방법, 전직에 필요한 시간, 전직 장소, 되돌리기 비용, 실패/랜덤 결과의 스트레스 완화 방법
**전투** — 6인 고정 여부, 전투 화면의 형태, 자동전투 방식, 스킬 개수, 전투 지형, 전투 결과가 교역에 미치는 영향, PvP 여부
**멀티플레이** — 처음부터 온라인인가, 싱글플레이 기반으로 시작하는가, 플레이어 간 직접 거래, 캐러밴 충돌, 경쟁의 최종 목표
**게임 목표** — 자유롭게 무한 플레이, 상단 등급 달성, 특정 지역 장악, 최종 캐릭터 수집, 경제적 목표, 시즌제

## 27. 1차 프로토타입 제안

처음부터 전체 시스템을 만들지 않는다.

**세계** — 도시 3개, 교역품 5개
**교역** — 구매, 판매, 가격 변화, 이동시간
**캐릭터** — 기본 캐릭터 3명, 직업 3~4개, 간단한 전직 트리, 랜덤 전직
**전투** — 3인 편성, 자동전투, 캐릭터당 특성 1개, 스킬 1개, 간단한 전투 연출

목표: "교역 → 캐릭터 성장 → 전직 → 전투 → 다시 교역"의 전체 사이클이 재미있는지 확인한다.
아직 멀티플레이, 대규모 경제 시스템, 복잡한 전투, 수십 개 도시, 대규모 캐릭터 수집 등은 넣지 않는다.

## 28. 현재 가장 중요한 디자인 질문

1. "플레이어가 다음 교역을 왜 하고 싶은가?"
2. "왜 이 캐릭터를 얻고 싶어 하는가?"
3. "왜 다른 플레이어보다 내가 더 잘하고 싶어지는가?"

이 세 가지가 해결되면 교역·전직·전투·멀티플레이의 세부 시스템을 결정할 수 있다.
