# 90 — 미결 질문

각 문서의 `[미결]` 을 한곳에 모은 것이다. 원문 26장에 대응한다.

**중요한 건 "언제 답할 것인가" 칸이다.** 지금 답하지 않기로 한 것도 미결이고,
그걸 지금 답하려 들면 근거 없이 정하게 된다.

---

## 1. 지금 답해야 하는 것

프로토타입 1단계를 시작하기 전에 정해야 한다.

| 질문 | 문서 | 비고 |
|---|---|---|
| 기술 스택 | `20` 6장 | 1단계 착수 전까지. 그전엔 무관 |
| 도시·품목 이름 확정 | `01` 5장 | 데이터로 두면 언제든 바꿀 수 있어 급하지 않다 |

**둘뿐이다.** 나머지는 전부 만들어보고 답하는 게 낫다.

---

## 2. 프로토타입에서 답이 나오는 것

만들어서 재보면 답이 나온다. **미리 정하면 안 되는 것들**이다.

| 질문 | 문서 | 어떻게 답하는가 |
|---|---|---|
| 가격 수식의 탄력도 `e` 값 | `02` 4장 | 시세 추정이 되는지 재본다 |
| NPC 상인 속도·물량 | `09` 2장 | 경제가 발산/고갈되는지 본다. **가장 오래 만질 숫자** |
| 이동 시간·위험도 밸런스 | `03`, `05` | 늑대고개를 갈지 고민되는지 본다 |
| 전직 확률·천장 배수 | `07` | "아깝다"인지 "짜증난다"인지 본다 |
| 최종 확률 공개 여부 | `07` 3장 | 계산을 실제로 하는지 본다 |
| 시간 배율 (6× vs 1×) | `03` 3장 | 기다림이 긴장인지 지루함인지 본다 |
| 능력치 경험치 성장 넣을지 | `06` 3장 | 전직만으로 성장감이 나는지 본다 |
| 계절을 넣을지 | `09` 5장 | 이벤트만으로 충분한지 본다 |
| 3인이면 충분한지, 6인이 필요한지 | `05` 2장 | 3칸 편성이 고민되는지 본다 |
| 영구 상실(인물 사망)을 넣을지 | `08` 5장 | 긴장이 부족한지 본다 |

---

## 3. 루프가 재미있다고 확인된 뒤에 답할 것

**순서가 중요하다.** 이것들을 먼저 답하면 잘못된 전제 위에 쌓게 된다.

| 질문 | 문서 |
|---|---|
| 게임의 최종 목표 (무한 / 등급 / 수집 / 장악 / 시즌제) | `10` 3장 |
| 멀티플레이 도입 시점과 범위 | `10` 4장 |
| 플레이어 간 정보 거래에서 거짓 정보 허용 여부 | `04` 6장, `10` 4장 |
| 캐러밴 충돌·PvP | `08` 7장, `10` 4장 |
| 경제 리셋 / 시즌제 | `02` 7장 |
| 캐러밴 여러 대 운영 | `05` 7장, `10` 1장 |
| 거점·창고·생산 가공 | `05` 7장 |
| 지역(region) 상위 단위 | `01` 6장 |
| 국가·전쟁·정치 | `01` 6장, `09` 5장 |
| 과금 구조 | `10` 5장 |

---

## 4. 답을 미루면 나중에 비싸지는 것

위 분류와 별개로, **일찍 생각해두지 않으면 나중에 되돌리기 어려운 것**들이다.
지금 결정하라는 뜻은 아니고, 결정할 때 비용이 크다는 걸 기억해두자는 뜻이다.

### 인물을 얻는 방법 `06` 6장

**가장 위험한 미결 항목.** 뽑기를 넣느냐 마느냐가
`00` 의 두 번째 질문("왜 이 캐릭터를 얻고 싶어 하는가")의 답을 통째로 바꾼다.
프로토타입은 뽑기 없이 간다 — 없이도 수집욕이 생기는지 먼저 본다.

### 고유 캐릭터의 외형 `06` 7장

**비용이 가장 큰 항목.** 고유 캐릭터마다 그림이 필요하고,
`08` 3장에 따르면 그 그림이 곧 보상이다. 캐릭터를 몇 명까지 만들 수 있는지가
그림 예산으로 정해지고, 그게 직업 트리 규모를 정한다.
**트리 규모를 정하기 전에 그림 비용을 먼저 알아야 한다.**

### 각성 조건 `06` 4장, `07` 8장

무엇을 하면 리안이 되고 무엇을 하면 다른 해적왕이 되는가.
프로토타입은 고유 캐릭터가 2명뿐이라 이 질문이 안 떠오르지만,
**여기서 정한 규칙이 이후 모든 캐릭터 설계를 구속한다.**

### 해로 `01` 6장, `03` 7장

리안의 "해상 특화"가 의미를 가지려면 해로가 육로와 달라야 한다.
프로토타입에는 해로가 없어서 **리안이 반쪽으로만 검증된다.**
이건 프로토타입의 알려진 한계다 — 결과를 해석할 때 감안한다.

---

## 5. 답이 나온 것

원문 26장 중 이 저장소에서 답한 것들. 다시 열 수 있지만, 열 때는 이유를 적는다.

| 질문 | 답 | 문서 |
|---|---|---|
| 시대 / 문화권 | 중세 후기~근세 지중해풍 | `01` 1장 |
| 판타지 여부 | 낮은 판타지. 마법 없음 | `01` 1장 |
| 세계 크기 | 정식 20~30 도시 | `01` 2장 |
| 프로토타입 도시 수 | 3 | `01` 4장 |
| 가격 계산 방식 | 재고 기반 + 적분 가격 | `02` 2·3장 |
| 상품 종류 | 5종 (프로토타입) | `02` 4장 |
| 6인 고정 여부 | 6인 확정, 프로토타입은 3인 | `05` 2장 |
| 자동전투 방식 | 완전 자동, 건너뛰기 가능 | `08` 2장 |
| 전투 결과 | 5단계, 인물은 죽지 않음 | `08` 5장 |
| 전직 확률 구조 | 곱셈 가중치 + 정규화 | `07` 2장 |
| 확률을 높이는 방법 | 도시 · 능력치 · 교관 · 이벤트 | `07` 2장 |
| 되돌리기 비용 | 시간 50% + 비용 80%, 누적 ×1.5 | `07` 6장 |
| 스트레스 완화 | 모든 갈래를 쓸 만하게 + 천장 | `07` 1·4장 |
| 처음부터 온라인인가 | **아니오.** 싱글부터 | `10` 4장 |
| PvP 여부 | 안 넣음. 경쟁 축은 경제 | `08` 7장, `10` 4장 |
