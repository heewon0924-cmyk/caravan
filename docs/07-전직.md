# 07 — 전직

원문 10~13장에 답하는 문서다. 이 게임에서 **가장 조심해서 다뤄야 할 시스템**이다.

랜덤 전직은 잘 되면 이 게임의 얼굴이 되고, 잘못되면 플레이어를 쫓아낸다.
그 차이는 확률값이 아니라 **실패했을 때 무슨 일이 일어나는가**에서 갈린다.

---

## 1. 이건 강화가 아니다 `[확정]`

> 랜덤 전직의 핵심은 "성공/실패"가 아니라 **"어느 길로 갔는가"** 다. (원문 10장)

강화는 성공 아니면 실패다. 실패하면 아무것도 안 남는다.
전직은 **무조건 무언가가 된다.** 원하는 게 아닐 수는 있어도, 아무것도 아닌 상태는 없다.

이 차이를 설계 전체에서 지킨다.

* "전직 실패" 라는 표현을 쓰지 않는다. **"다른 결과"** 다
* 모든 갈래에 쓸모가 있어야 한다. 원치 않은 결과도 **누군가에게는 최적**이어야 한다
* 결과가 나왔을 때 화면에 뜨는 문구는 "실패했습니다"가 아니라 **"그는 용병이 되었다"** 다

용병이 쓰레기면 용병이 나온 건 실패다. 문구를 아무리 예쁘게 써도 플레이어는 안다.
**모든 갈래를 쓸 만하게 만드는 것**이 스트레스 완화의 90%다. 나머지 장치는 전부 보조다.

---

## 2. 확률은 가중치로 다룬다 `[확정]`

퍼센트를 직접 더하지 않는다. **가중치를 곱하고 마지막에 정규화한다.**

```
P(결과 i) = W(i) / Σ W(j)
W(i) = 기본가중치(i) × 도시보정 × 능력치보정 × 준비보정 × 이벤트보정 × 천장보정
```

퍼센트를 더하면 100%를 넘거나 음수가 되는 걸 계속 막아야 하고,
보정을 하나 추가할 때마다 기존 밸런스가 깨진다. 곱셈 가중치는 그럴 일이 없다.

### 기본 가중치 — 검사 `[제안]`

| 결과 | 가중치 | 보정 없을 때 |
|---|---:|---:|
| 해적 | 40 | 40% |
| 창잡이 | 40 | 40% |
| 용병 | 20 | 20% |

### 보정 `[제안]`

| 보정 | 조건 | 배수 |
|---|---|---:|
| 도시 | 셀리아에서 해양 계열 | ×3.0 |
| | 카르덴에서 중장 계열 | ×3.0 |
| | 수련처 없는 도시 (하른) | 전직 불가 |
| 능력치 | 인물의 주 능력치가 계열과 일치 (상위 30%) | ×1.5 |
| | 계열과 어긋남 (하위 30%) | ×0.7 |
| 준비 | 교관 고용 (비용 지불) | ×1.5 |
| | 관련 소문 활용 (`04`) | ×1.2 |
| 이벤트 | '해적 창궐' 중 해양 계열 | ×2.0 |
| 천장 | 4장 참조 | ×1.0 ~ ×4.0 |

### 계산 예 — 셀리아에서 해적왕을 노린다

무력이 높은 검사를 셀리아에서 교관까지 붙여 전직시킨다.

| 결과 | 계산 | 가중치 |
|---|---|---:|
| 해적 | 40 × 3.0(셀리아) × 1.5(무력) × 1.5(교관) | **270** |
| 창잡이 | 40 × 1.0 × 1.0 × 1.0 | 40 |
| 용병 | 20 × 1.0 × 1.0 × 1.0 | 20 |

→ 해적 **81.8%**, 창잡이 12.1%, 용병 6.1%

원문 12장의 *"내 계산으로 해적왕 루트가 약 80% 정도 되겠는데?"* 가 **실제로 계산 가능하다.**
그리고 18% 확률로 다른 게 나온다. 그 18%가 긴장의 정체다.

## 3. 최종 확률을 화면에 띄우지 않는다 `[제안]`

**보정 요인은 전부 공개한다. 합산된 최종 확률은 보여주지 않는다.**

| 보여주는 것 | 안 보여주는 것 |
|---|---|
| "셀리아는 해양 계열 전직에 크게 유리하다 (×3)" | "해적 81.8%" |
| "이 인물은 무력이 높다 (×1.5)" | |
| "교관을 고용하면 유리해진다 (×1.5)" | |
| 기본 가중치표 (도감에 영구 기록) | |

이유가 원문 12장에 이미 적혀 있다. *"플레이어는 이러한 정보를 수집하고 **스스로** 확률을 계산한다."*

최종 숫자를 띄워주면 플레이어가 하는 일은 **버튼을 누를지 말지 정하는 것뿐**이 된다.
계산을 플레이어에게 남겨두면 **정보를 모으는 것이 곧 계산 정확도**가 되고,
`04` 의 정보 시스템이 전직과 직접 연결된다.

`[미결]` 다만 이건 진입장벽이 될 수 있다. 프로토타입에서 반드시 재본다 —
계산을 아예 포기하고 대충 누르는 플레이어가 다수면 최종 확률을 공개하는 쪽으로 돌린다.
그때도 **정확한 숫자가 아니라 "매우 유력 / 유력 / 반반 / 희박"** 4단계로 보여주는 절충안을 먼저 시도한다.

---

## 4. 스트레스 완화 `[제안]`

1장의 "모든 갈래가 쓸 만하다"가 본체이고, 아래는 보조 장치다.

### 천장 — 같은 인물이 같은 목표를 계속 놓치면

같은 인물이 같은 목표 전직을 놓칠 때마다 **그 목표의 가중치가 누적된다.**

| 누적 실패 | 천장 배수 |
|---:|---:|
| 0회 | ×1.0 |
| 1회 | ×1.6 |
| 2회 | ×2.4 |
| 3회 | ×3.4 |
| 4회 이상 | ×4.0 (상한) |

위 예시(가중치 270 / 40 / 20)에서 두 번 놓치면 해적 가중치가 648이 되어 **91.5%** 가 된다.
**확정은 아니다.** 확정을 주면 "몇 번만 하면 된다"가 되어 확률이 의미를 잃는다.
대신 **계속 놓치는 일은 거의 없게** 만든다.

천장은 **인물 단위 · 목표 단위**로 쌓인다. 다른 인물로 갈아타면 초기화된다 —
그래야 한 인물을 끝까지 밀어붙일 이유가 생기고, 그게 애착으로 이어진다.

### 확률은 정직하게 굴린다 `[확정]`

* 보이는 가중치가 **실제로 쓰이는 값**이다. 숨은 보정을 넣지 않는다
* 연속 실패를 유도하는 어떤 장치도 넣지 않는다
* 난수는 서버에서 굴리고, 시드와 결과를 기록해 **나중에 검증 가능하게 둔다**

원문 12장: *"실제 확률은 공정하게 동작해야 하며"*. 이건 `[확정]` 이고 협상 대상이 아니다.
플레이어가 조작을 의심하기 시작하면 이 게임에서 고칠 수 있는 건 없다.

## 5. 시간과 비용 `[제안]`

전직은 **도시에 머무는 동안에만 진행된다** (`03` 6장). 이동 중에는 멈춘다.

| 티어 | 소요 (세계시간) | 비용 |
|---|---:|---:|
| 1→2티어 | 6h | 500 G |
| 2→3티어 | 18h | 3,000 G |
| 각성 | 36h | 12,000 G + 조건 |
| 교관 고용 | — | 전직 비용의 60% 추가 |

여기서 진짜 비용은 돈이 아니라 **시간**이다.
6시간을 셀리아에 앉아 있으면 그동안 하른↔카르덴을 세 번 왕복할 수 있었다.
**그 왕복이 전직의 진짜 가격이다.** 원문 11장이 말한 "이동과 전직의 연결된 자원 구조"가 이것이다.

그래서 이런 결정이 생긴다.

* 지금 셀리아에서 6시간 서 있을 것인가, 한 바퀴 더 돌고 올 것인가
* 하른에서 바로 시도할 수는 없다 — 수련처가 없다 (`01`)
* 카르덴에서 창잡이로 가는 게 확률은 좋은데, 나는 해적왕이 목표다

---

## 6. 되돌리기 `[제안]`

원문 13장. 원치 않는 결과가 나오면 **이전 직업으로 되돌아가 다시 시도할 수 있다.**

| 항목 | 값 |
|---|---|
| 소요 | 직전 전직 소요의 50% (1→2티어면 3h) |
| 비용 | 직전 전직 비용의 **80%** |
| 반복 | 같은 인물이 되돌릴 때마다 비용 **×1.5** 누적 |
| 능력치 | 그 전직으로 오른 능력치는 **되돌아간다** |
| 천장 | **유지된다** — 되돌려도 누적 실패는 남는다 |

3회 되돌리면 비용이 `500 × 0.8 × 1.5² = 900 G` 에 시간 9h. 시간이 먼저 아파온다.

되돌리기를 허용하되 **천장을 유지하는 게 핵심**이다.
되돌리면서 천장이 쌓이므로, **되돌릴수록 원하는 결과가 가까워진다.**
"계속 실패해서 화나는" 상황이 "돈과 시간을 얼마나 더 쓸 것인가"라는 **판단**으로 바뀐다.

한편 새 인물을 구해 처음부터 시작하는 선택지도 있다 — 천장은 없지만 싸고 빠르다.
**되돌리기 vs 새 인물**, 이 저울이 전직 시스템의 마지막 결정이다.

---

## 7. 검증해야 할 것

1. 전직 결과를 보고 **"아깝다"** 인가 **"짜증난다"** 인가 — 이 한 줄이 전부다
2. 원치 않은 결과(용병)를 받고도 **그 인물을 계속 쓰는가**, 아니면 즉시 되돌리는가
   — 즉시 되돌린다면 용병이 쓸모없다는 뜻이고, 그건 1장이 무너졌다는 뜻이다
3. 플레이어가 **실제로 확률을 계산하는가**, 아니면 그냥 누르는가 (3장)
4. 전직하러 가느라 교역을 포기하는 결정이 **아깝게 느껴지는가**
   — 안 아까우면 시간 비용이 너무 싸다
5. 각성 결과가 여러 개일 때 **"이게 나와서 기쁘다"** 가 되는가 (`06` 4장)

## 8. 아직 안 정한 것 `[미결]`

* 각성에 필요한 '조건'의 구체적 내용 (`06` 4장) — 어떤 길을 걸어야 리안이 되는가
* 3티어 이상에서 되돌리기를 허용할 것인가. 각성은 되돌릴 수 없어야 할 것 같다
* 전직 중에 다른 인물로 캐러밴을 굴릴 수 있는가 (캐러밴 1대 제약과 충돌)
* 천장 배수가 4.0 상한이 맞는가
