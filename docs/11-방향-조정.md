# 11 — 방향 조정 (v0.3)

원본 기획서(`99`) 이후 방향이 한 번 더 잡혔다. 이 문서는 **무엇이 바뀌었고,
그게 이미 만든 것과 앞으로 만들 것에 무엇을 하는지**를 적는다.

기존 문서를 소급해서 고치지 않는다. 어긋나는 부분은 여기에 적고,
실제로 손댈 때가 되면 그 문서에서 이 문서를 가리킨다.

---

## 1. 새 방향 `[확정]`

> **대항해시대 + 거상.**

| | |
|---|---|
| 교역 | **육상이 기본** |
| 해상 | 존재하지만 **메인 시스템은 아님** |
| 캐릭터 | **수집·육성의 비중이 크다** |
| 전투 | 단순한 부가 시스템보다 **어느 정도 볼륨을 갖는다** |
| 구조 | 상단을 이끌고 여러 지역을 돌며 **교역 · 탐험 · 사건 · 전투** |

**지금 프로토타입을 다시 설계하지 않는다.** 1~4단계에서 만든 것은 전부 기반이고
어느 방향이든 그대로 쓴다.

---

## 2. 안 바뀌는 것

이미 만든 것 중 이 방향 변경에 영향을 받는 것은 **없다.**

| | 왜 그대로인가 |
|---|---|
| 가격 수식 · 적분 가격 (`02`) | 품목이 5개든 30개든 같은 식이다 |
| 세계 시간 · 오프라인 진행 (`03`) | 지역이 늘어도 구조가 안 바뀐다 |
| 거래소 (`Exchange`) | 주체가 플레이어든 NPC든 같은 함수 |
| 이동 · 노선 (`travel`) | 해로도 노선 하나로 들어간다 |
| NPC 상인 · 사건 (`09`) | 도시가 늘면 인원 공식만 다시 푼다 |
| 밸런스를 데이터로 두기 (`20` 5장) | 세계가 커질수록 더 중요해진다 |
| **서버·클라이언트 경계 (`31`)** | **더 중요해진다** — 아래 3장 |

## 3. 전투 볼륨이 가장 큰 변수다 `[미결 — 지금 답하지 않지만 알고는 있어야 한다]`

`08` 1장은 **"전투는 메인 콘텐츠가 아니라 교역 과정의 위험 요소"** 를 전제로 썼고,
그 위에 두 결정이 서 있다.

* **자동전투** (`08` 2장) — 플레이어가 전투 중에 아무것도 하지 않는다
* **전투 리플레이** (`31` 4장) — 서버가 끝까지 굴려 일어난 일의 목록을 내려주고
  클라이언트는 재생만 한다

**"볼륨 있는 전투" 가 "수동 조작" 을 뜻하지는 않는다.** 이 구분이 중요하다.

| 볼륨을 주는 방법 | 자동전투와 리플레이 구조 |
|---|---|
| 편성 깊이 (6칸 조합 · 전열/후열 · 역할 상성) | **그대로 산다** |
| 스킬 수와 발동 조건 | **그대로 산다** |
| 지형 · 적 종류 · 전투 전 준비 | **그대로 산다** |
| 장비 · 진형 · 전투 전 지시 | **그대로 산다** |
| **전투 중 실시간 조작** | **무너진다** |

마지막 하나만 구조를 깬다. 실시간 조작이 들어가면 클라이언트가 전투 규칙을 알아야 하고,
그러면 `31` 의 경계가 새고, 멀티에서 조작이 가능해지고, 클라이언트를 갈아끼울 때
전투를 통째로 다시 만들어야 한다.

**권하는 방향: 자동전투를 유지하되 편성과 스킬로 볼륨을 준다.**
오토체스 계열이 이미 증명한 길이다 — 조작이 없어도 깊이가 나온다.

> 이건 7~8단계에 실제로 만들 때 정하면 된다. 다만 **지금 편한 대로 수동 조작을
> 넣어두면 나중에 되돌리는 값이 크다**는 것만 기억해 둔다.

## 4. 탐험이 새 축이다 `[미결]`

원문(`99`)과 `00`~`10` 어디에도 탐험이 없다. 새로 들어온 것이다.

다행히 **넣는 비용 자체는 싸다.** 도시 · 노선 · 사건이 전부 데이터라
(`cities.yml` · `routes.yml` · `events.yml`) 유적이나 미개척지를 목적지로 추가하는 데
코드가 거의 안 든다.

**비싼 건 "탐험으로 무엇을 얻는가" 다.** 얻는 것이 경제에 어떻게 들어오는지를 정해야 한다.

| 후보 | 경제에 미치는 영향 |
|---|---|
| 새 교역품 | 품목이 늘어난다. 가격 수식은 그대로 |
| 새 도시 · 항로 | 노선망이 커진다. NPC 처리량 공식을 다시 푼다 (`24` 6장) |
| 인물 | **`06` 6장의 "가장 위험한 미결" 에 답이 될 수 있다** — 아래 6장 |
| 보물 · 자금 | 교역 밖에서 돈이 들어온다. **교역의 의미를 깎을 위험** |
| 지도 · 정보 | `04` 의 정보 시스템과 직결된다 |

**"보물로 돈을 번다" 는 조심해야 한다.** 교역보다 탐험이 돈이 되면
`00` 의 첫 질문("플레이어가 다음 교역을 왜 하고 싶은가")이 무너진다.
탐험의 보상은 **돈이 아니라 교역을 더 잘하게 해주는 것**이어야 한다 —
새 품목, 새 항로, 새 인물, 정보.

## 5. 해상이 부차적이면 리안의 자리가 애매해진다 `[미결]`

`06` 5장에서 해적왕 리안은 **해상 특화**로 설계했다. 해로 소요 −25%, 해상 습격 −50%,
항구 거래세 −1%. 해상이 메인이 아니면 리안은 대부분의 시간 동안 "그냥 센 전투원 한 명"
이 된다.

`06` 5장이 스스로 세운 기준이 있다.

> 최종 캐릭터를 설계할 때마다 반드시 답한다:
> **"이 캐릭터가 쓸모없어지는 상황은 언제인가?"**

리안의 답이 "육상 교역을 할 때" 인데, 육상이 기본이면 **쓸모없는 시간이 너무 길다.**
조정이 필요하다.

* 육상 계열 고유 캐릭터를 더 많이 둔다 (블래스티 쪽이 표준이 된다)
* 해상 캐릭터는 **소수 · 특정 구간에서 압도적** 으로 둔다 —
  드물게 쓰지만 쓸 때는 대체 불가
* 또는 리안의 특성을 "해상" 이 아니라 "위험한 길" 로 넓힌다
  (늑대고개 같은 육상 위험 구간에도 걸리게)

**프로토타입에는 영향 없다.** 3도시에 해로가 없어서 어차피 반쪽으로만 검증된다
(`90` 4장에 이미 적혀 있다).

## 6. 캐릭터 비중이 커지면 "어떻게 얻는가" 가 더 급해진다 `[미결 — 가장 위험]`

`06` 6장이 이미 **가장 위험한 미결**로 꼽아둔 항목이다. 수집 비중이 커지면 압력이 는다.

위험은 하나다 — **수집 비중이 크면 뽑기가 당겨진다.** 그런데 뽑기를 넣는 순간
`00` 의 두 번째 질문에 대한 답이 바뀐다.

| | 답 |
|---|---|
| 지금 (`00` ②) | "내가 그 길을 골라서 거기까지 데려갔기 때문에" |
| 뽑기를 넣으면 | "운 좋게 나왔기 때문에" |

후자가 나쁜 건 아니지만 **이 게임의 다른 모든 설계와 안 맞는다.**
직업 트리(`06` 4장), 랜덤 전직(`07`), 전직 도시까지 가는 기회비용(`07` 5장)이
전부 "만들어가는 수집" 위에 서 있다. 뽑기가 들어오면 그 셋이 장식이 된다.

**탐험이 대안이 될 수 있다** (4장). "새 지역에서 인물을 만난다" 는 수집이면서
플레이어의 선택이다 — 어디를 탐험할지 고른 것이 나이니까.

지금 정할 필요는 없다. 다만 **인물 수급을 설계할 때 이 문서를 먼저 읽는다.**

## 7. 세계가 커지는 것에 대해 `[제안]`

`01` 2장은 정식 20~30 도시로 잡았고, 이유는 "한 사람이 머릿속에 지도를 그릴 수 있는 크기"
였다. 대항해시대 느낌이면 더 커지고 싶어진다.

**상한을 늘리되 그 논리는 지킨다.** 방법은 **지역(region) 계층**이다 (`01` 6장의 미결).

```
지역 4~6개 × 지역당 도시 5~8개  →  전체 25~45
```

플레이어는 한 번에 한 지역을 읽고, 지역 간 이동은 드물고 크다.
그러면 도시가 40개여도 머릿속 지도는 지역 단위로 그려진다.

**NPC 처리량 공식을 다시 풀어야 한다** (`24` 6장). 지역 안에서 도는 NPC 와
지역을 넘나드는 NPC 를 나눠야 할 가능성이 높다.

## 8. 무엇을 지금 하고 무엇을 미루나

| | |
|---|---|
| **지금** | 5단계(소문)까지 계획대로. 이 방향 변경은 5단계에 영향이 없다 |
| **6단계에서 볼 것** | 인물 비중이 커진 만큼 6칸 편성을 3칸이 아니라 처음부터 6칸으로 갈지 |
| **7~8단계에서 정할 것** | 전투 볼륨과 자동전투 유지 여부 (3장). **여기가 갈림길이다** |
| **프로토타입 이후** | 탐험 · 지역 계층 · 해상 · 인물 수급 |

**순서를 바꾸지 않는다.** `20` 4장이 제일 위험한 걸 제일 먼저 만들자고 정했고,
방향이 커졌다고 해서 교역 루프가 재미있는지 확인하는 일이 덜 중요해지지 않는다.
오히려 그 위에 얹을 것이 많아졌으니 **바닥이 더 튼튼해야 한다.**
